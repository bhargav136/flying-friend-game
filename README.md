# Flying Sai 🚀

A Flappy Bird style browser game recreation featuring custom player avatar, background theme, obstacles, and meme sound effects.

## 🎮 Play Live
**[https://flying-friend-game.vercel.app](https://flying-friend-game.vercel.app)**

## 🌟 Features
- **Custom Player (Bird)**: Person cutout with background removed.
- **Background Music**: Telugu track with unmute/mute toggle.
- **Pillars & Obstacles**: Dynamic pipes featuring custom mascot badges.
- **Game Over Screen**: Reaction overlay displaying current score, best score, and instant restart.
- **Responsive Controls**:
  - **Spacebar / Up Arrow** (Desktop)
  - **Click / Tap** (Desktop & Mobile)
- **High Score Tracking**: Saved in browser `localStorage`.
